# Resume Impact Lab

`/impact-lab` now accepts user-provided resume/job text and candidate answers. It runs
local assessment, immutable requirement-level reassessment and evidence-grounded review/
copying in page memory. It replaces PR #39's fixed-only fictional prototype.

See [Evidence ledger implementation and integration handoff](EVIDENCE_LEDGER.md) for the
real workflow, repeatable optional sample, exact source rules, tests, limitations and
Fit Explorer/interview API dependencies. No live model calls, uploads or persistence
are implemented. The older `docs/images/impact-lab-*` screenshots record the previous
prototype; current screenshots are linked from the implementation notes.
